<h1 align="center">47th-web</h1>
<p align="center">
KAPA의 47회 전시회를 위해 제작 배포되는 웹사이트입니다.<br/> 
KAPA 41기 박우석, 42기 최승아가 제작하였습니다.
</p>

---

## 🌐 Link

🔗 [KAPA 47회 정기 전시회 바로가기](https://www.kapaforever.site/)

---

## ✨ Features

- HOME, VISIT, EXHIBITION, GOODS로 구분된 명확한 정보 구조
- Lottie 애니메이션을 활용한 동적인 로고파일 생성
- 모바일 및 데스크탑에 최적화된 반응형 UI
- TailwindCSS 기반의 일관된 디자인 시스템
- Vercel 배포 및 배포 파이프라인 자동화
